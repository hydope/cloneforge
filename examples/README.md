# Examples

Run from the repo root after ./install.sh:

```bash
LINE="The quick brown fox jumps over the lazy dog near the river bank."
.venv/bin/cloneforge reference --text "$LINE" --out examples/output/reference.wav
.venv/bin/cloneforge synth --text "$LINE" --reference examples/output/reference.wav --out examples/output/clone-dsp.wav
.venv/bin/cloneforge synth --backend yourtts --text "$LINE" --reference examples/output/reference.wav --out examples/output/clone-yourtts.wav
.venv/bin/cloneforge bench --text "$LINE" --reference examples/output/reference.wav --out-dir examples/output/bench
```

All speakers here are SYNTHETIC (generated by Piper). No real person's voice is used in any example. Output is git-ignored; the committed proof of a full run is docs/PROOF-2026-11-23.md.
